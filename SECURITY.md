# Security Policy

AwareMate handles personal reflection and digital-wellbeing data. Please report suspected vulnerabilities responsibly and privately.

## Supported versions

Security fixes are currently provided for the latest `1.0.x` release and the `main` branch.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/husoelrey/AwareMate/security/advisories/new) and include:

- the affected version or commit;
- clear reproduction steps;
- the expected and observed behavior;
- the potential impact;
- any suggested mitigation, if known.

Do not include secrets, personal journal content, access tokens, or other users' data in a report. Please do not open a public issue for an unpatched vulnerability.

You can expect an initial acknowledgement within seven days. Valid reports will be investigated, fixed according to severity, and disclosed after a patch is available.

## Scope

Reports about authentication, authorization, Firestore access, account deletion, private file sharing, sensitive local data exposure, leaked credentials, or dependency vulnerabilities are in scope.

General bugs and feature requests should use the public issue templates instead.
